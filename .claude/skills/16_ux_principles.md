# Skill 16: UX 원칙 (UX Lenses)

## 목적
UI 문서(스킬 07~11)를 만들 때 항상 켜 두는 **5개 렌즈**를 정의한다.
기능이 맞는지(추적성)와 별개로, **사용자가 실제로 목표를 이룰 수 있는 화면인가**를 단계마다 판정하기 위한 공통 기준이다.

> **이 문서는 렌즈의 정본이다.** 스킬 07~11은 이 문서를 재기술하지 않고 자기 단계에서 **판정 가능한 항목만** 체크리스트로 갖는다(값 중복 금지 — 스킬 15 영역 F).
> **접근성 수치의 정본은 여기가 아니다.** 대비·터치 타깃·줄 길이·모션 기준은 `.claude/design-system/design-playbook.md` 1.6·1.8·1.9가 정본이며, 이 문서는 **기획이 정할 것(누가 어떤 환경에서 쓰는가)만** 다룬다.

---

## 5개 렌즈

| 렌즈 | 판정 질문 (이 질문에 구체적으로 답할 수 없으면 미완성이다) |
|---|---|
| **유용성** | 이 화면·경로가 **어떤 REQ의 사용자 목표**를 달성시키는가? 목표를 못 대면 그 화면은 삭제 후보다 |
| **가시성** | 사용자가 **지금 어디에 있고 / 무엇을 할 수 있고 / 다음에 무슨 일이 일어나는지** 화면만 보고 아는가? 시스템 상태(처리 중·완료·실패)가 표시되는가? |
| **효율성** | 목표까지 **화면 이동 수·필수 입력 수**가 몇인가? 반복 작업에 기본값·직전 값·일괄 처리가 있는가? |
| **참여도** | 성공·실패 피드백이 **무슨 일이 일어났고 다음에 뭘 하면 되는지**를 말하는가? 문구의 톤이 이 사용자에게 맞는가? |
| **접근성** | 이 화면을 **쓰기 어려운 조건**(저시력·색각이상, 키보드 전용, 소음·장갑, 구형 브라우저, 장시간 응시)이 무엇이고, 그 전제가 문서에 적혔는가? |

- **RULE 판정은 구체적으로 적는다.** "직관적", "편리한", "빠른"은 판정이 아니다(CLAUDE.md `금지 사항`). "3화면 이동 / 필수 입력 4개"처럼 세어서 적는다.
- **RULE 렌즈는 5개 전부 돌린다.** 해당 없는 렌즈는 "해당 없음 + 이유"를 남긴다.

## 단계별 적용 지점

| 렌즈 | 판정 주체 | 그 문서에서 실제로 판정하는 것 |
|---|---|---|
| 유용성 | 07 IA · 08 플로우 | REQ의 사용자 목표가 화면·경로로 번역됐는가. 목표 없는 화면 적발 |
| 가시성 | 07 · 09 화면명세 · 11 UI 생성 | 현재 위치 표시, 다음 단계 안내, 상태(로딩·성공·실패) 노출 |
| 효율성 | 08 · 09 | 단계 수·필수 입력 수, 반복 작업의 기본값 |
| 참여도 | 09(문구) · 10 디자인 방향 | 피드백 문구의 내용과 톤, 도메인 용어 |
| 접근성 | 10(사용 환경 전제 확정) · 11(playbook 준수) | 사용 환경 제약을 문서화. 수치 준수는 `/design-review`가 판정 |

## UX 발견 처리 규칙 (필수)

렌즈로 찾은 개선점을 **명세에 바로 쓰지 않는다.** 셋 중 하나로 보낸다.

1. **REQ 근거 있음** — 화면 항목으로 반영하고 출처 칸에 `REQ-###`·`EC-##`를 적는다.
2. **근거 없음** — 미결(❓)로 남기고 `AskUserQuestion`으로 되묻는다. **임의 반영 금지.**
3. **PRD 변경이 필요함** — v0.x는 PRD를 직접 수정, v1.0 확정 이후는 스킬 14 CR 절차.

> "효율성을 위해 자동완성 추가", "참여도를 위해 축하 애니메이션", "가시성을 위해 대시보드 신설" 같은 **우리 발(發) 기능 추가가 이 규칙의 표적**이다. UX 원칙은 **사용자가 정하지 않은 범위를 채워 넣는 근거가 되지 않는다**(CLAUDE.md 절대원칙 7 · `임의 구체화 금지`).

---

## 금지

- 렌즈를 근거로 REQ 없는 기능·요소를 명세·화면에 추가 금지 (위 처리 규칙 2번으로 보낸다)
- 접근성 수치(대비비·px·초)를 이 문서나 UI 문서에서 새로 선언 금지 — `design-playbook.md`가 정본
- "사용성이 좋다/직관적이다" 같은 추상 표현으로 판정 기재 금지 — 세어서 적는다
- 렌즈 점검 결과를 문서에 서사로 남기기 금지 — 판정은 체크리스트·표로, 경위는 ADR로(CLAUDE.md `근거 태그 층위`)
